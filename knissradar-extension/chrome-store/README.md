# Chrome Web Store Listing — KnissRadar

## Required Files

### Store Listing
- **Store Name:** KnissRadar: Ouedkniss Price History & Alerts
- **Short Description:** Track price history on any Ouedkniss listing. See 30/90-day price trends, get alerts when prices drop.
- **Detailed Description:** See `detailed-description.txt`

### Images (Required Sizes)
- **Icon:** 128x128 PNG (use existing `icons/icon128.png`)
- **Screenshots:** 1280x800 or 640x400 PNG (create 3-5 screenshots)
- **Marquee:** 1400x560 PNG (optional, for featured placement)

### Category
- **Primary:** Shopping
- **Language:** French

## Submission Checklist

- [ ] Build production extension: `npm run build`
- [ ] Zip the `dist/` folder
- [ ] Create Chrome Web Store developer account ($5 one-time fee)
- [ ] Upload zip to Chrome Web Store Developer Dashboard
- [ ] Fill in store listing details
- [ ] Upload screenshots
- [ ] Set privacy policy URL
- [ ] Submit for review

## Privacy Policy

Create a simple privacy policy at `knissradar.com/privacy` stating:
- Extension collects browsing data on ouedkniss.com only
- Data is used to track price history
- No personal data is sold or shared
- Users can opt out via settings

## Review Notes

Common rejection reasons to avoid:
- Don't request unnecessary permissions
- Don't inject ads into pages
- Don't collect data without user consent
- Ensure all features work as described
